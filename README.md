A short rant, written for the make.fun bounty "Angry Judge: The Short
Rant Contest", about the everyday humiliation of proving to a robot
that you are not one. The evidence is entered formally — parallel
parking, crying at a wedding, the bus in the blurry grid — and the
closing argument is the one every human has lost: the bicycle was
behind the pole.

## Running it

`node main.ts` clears the output directory's contents and writes the
rant to `/output/entry.txt` as plain UTF-8 text.
